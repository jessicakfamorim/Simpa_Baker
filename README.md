# Simpa Baker

Projeto desenvolvido no âmbito da nossa transição para a área de desenvolvimento web.

O **Simpa Baker** é um website de receitas com foco em pastelaria, pensado para ser simples, visual e fácil de usar. O objetivo é reunir receitas, tutoriais e conteúdos relacionados com confeitaria num só lugar.

---

## ✨ Funcionalidades atuais

- Página inicial com destaque visual e categorias
- Página de receitas com:
  - Cards de receitas
  - Campo de pesquisa dinâmica
  - Botão "Ver mais" para carregar mais conteúdos
- Página de tutoriais com:
  - Filtros por categoria
  - Modal com reprodução de vídeo
- Página de receita da semana
- Página de contactos com:
  - Formulário com validação em JavaScript
  - Feedback visual de envio com sucesso
